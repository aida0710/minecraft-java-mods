# minecraft-forge-mods

Personal Minecraft Forge mods (Kotlin).

| Mod | MC / Forge | Description |
| --- | --- | --- |
| [chat-translator](chat-translator/) | 26.3 / 66.0.x | Translates chat and item tooltips EN→JA with a local LLM (Ollama, etc.). Built for Hypixel SkyBlock. |

Each mod is an independent Gradle project in its own directory. CI builds every push; the built jars are uploaded as workflow artifacts.
