## 日本語

### 使うローダーの jar を 1 つ選ぶ

対応: Minecraft 26.3 / Java 25

| ローダー | jar | 必要なもの |
| --- | --- | --- |
| Forge 66 以降 | `chattranslator-forge-0.3.2.jar` | |

| Fabric Loader 0.19.5 以降 | `chattranslator-fabric-0.3.2.jar` | Fabric API |

### 直したこと

- **行の区切り**: 同じ色の行をまとめて訳していたので、`Amount: 3x` のような「ラベル: 値」の行や `✔` `▶` で始まる箇条書きが 1 行につながっていました。文の途中で折り返した行だけをつなげるようにしました
- **色**: 訳語が原文と変わると、§ で付けた色が消えていました。色の付いた語句をタグで囲んで翻訳エンジンに渡し、訳文の対応する語句にも同じ色を付けるようにしました。エンジンがタグを崩したときは、これまでと同じ方法で色を付けます
- **折り返し**: 訳文が長くなると、最後の 1〜2 文字だけが次の行に回っていました。元の行数に収まる幅で折り返すようにしました (幅は lore の 1.5 倍まで)

### 0.3.1 から更新するとき

- 色の付いた説明文は翻訳エンジンに送る文が変わるので、最初の 1 回は訳し直します
- OpenAI 互換 API でシステムプロンプトやプロンプトの雛形を自分で書いている場合は、`<s1>` などのタグを残すよう指示に書き足してください。書かなくても、タグが崩れたときはこれまでと同じ表示に戻ります

### 残っている制限

- 色が変わる行をまたぐ文は行ごとに訳すので、訳が不自然になることがあります

### 動作を確かめていないもの

- DeepL・Google 翻訳・Claude API での実際の翻訳 (送る内容だけをテスト用のサーバーで確かめました)
- PLaMo 3 Translate 0.8B 以外のモデルでのタグの扱い

## English

### Pick the jar for your loader

Requires Minecraft 26.3 and Java 25.

| Loader | Jar | Also needs |
| --- | --- | --- |
| Forge 66 or later | `chattranslator-forge-0.3.2.jar` | |
| NeoForge 26.3.0 or later | `chattranslator-neoforge-0.3.2.jar` | |
| Fabric Loader 0.19.5 or later | `chattranslator-fabric-0.3.2.jar` | Fabric API |

### What's fixed

- **Line breaks**: Lines of the same color were translated together, so "label: value" lines such as `Amount: 3x` and list items starting with `✔` or `▶` were merged into one line. Now only lines wrapped mid-sentence are joined
- **Colors**: § colors were lost when a translation did not contain the original words. Colored words are now wrapped in tags for the translation engine, and the matching words in the translation get the same color. If the engine breaks the tags, colors are applied the same way as before
- **Wrapping**: Longer translations left the last one or two characters alone on a new line. Text now wraps at a width that fits the original number of lines (up to 1.5 times the lore width)

### Updating from 0.3.1

- Colored tooltip text is sent to the translation engine in a new form, so it is translated once more the first time
- If you wrote your own system prompt or prompt template for an OpenAI-compatible API, add an instruction to keep tags such as `<s1>`. Without it, tooltips fall back to the previous display when the tags break

### Known limitation

- A sentence that crosses lines where the color changes is translated line by line, so the translation can read unnaturally

### Not verified

- Actual translation with DeepL, Google Translate and the Claude API (only the requests were checked, against a test server)
- How models other than PLaMo 3 Translate 0.8B handle the tags
- See "動作を確かめていないもの" in the README for the rest
