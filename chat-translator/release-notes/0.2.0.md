## 日本語

受信チャット・アイテムの説明・本を翻訳し、自分が送るチャットも翻訳して送れるクライアント専用の mod です。サーバーに入れる必要はありません。

### 使うローダーの jar を 1 つ選ぶ

対応: Minecraft 26.3 / Java 25

| ローダー | jar | 必要なもの |
| --- | --- | --- |
| Forge 66 以降 | `chattranslator-forge-0.2.0.jar` | |
| NeoForge 26.3.0 以降 | `chattranslator-neoforge-0.2.0.jar` | |
| Fabric Loader 0.19.5 以降 | `chattranslator-fabric-0.2.0.jar` | Fabric API |

`.minecraft/mods/` に入れて起動し、ワールドかサーバーに入ってから `/chattranslator` で設定画面を開きます。Kotlin の標準ライブラリは jar に入っているので、Kotlin for Forge や Fabric Language Kotlin は要りません。

### できること

- **チャット**: 届いたチャットを同じ行のまま訳文に置き換えます。ランクや名前の色はそのまま。行末の `[原文]` で元に戻せます
- **アイテムの説明**: 同じ色で続く行を 1 つの段落として訳し、元の幅で折り返します。`J` を押している間は原文
- **本**: 記入済みの本や書見台の本を、開いているページから順に訳します
- **送るチャット** (既定は OFF): 入力欄で Enter を押すと、書いた文を訳します (既定は 日本語 → English)。送る前に訳文を確かめられます
- **翻訳エンジン**: 内蔵 LLM (llama.cpp + TranslateGemma。無料・オフライン。設定画面の「インストール」で取得) / Claude / DeepL / Google / OpenAI 互換 API (Ollama・LM Studio など)
- **mod の画面**: 日本語 / English / 简体中文

設定は `config/chattranslator-client.toml` に保存されます。クラウドの API を選んだ場合、翻訳する文はそのサービスに送られます。

## English

A client-side mod that translates incoming chat, item tooltips and books, and can send your own chat translated. You do not need it on the server.

### Pick the jar for your loader

Requires Minecraft 26.3 and Java 25.

| Loader | Jar | Also needs |
| --- | --- | --- |
| Forge 66 or later | `chattranslator-forge-0.2.0.jar` | |
| NeoForge 26.3.0 or later | `chattranslator-neoforge-0.2.0.jar` | |
| Fabric Loader 0.19.5 or later | `chattranslator-fabric-0.2.0.jar` | Fabric API |

Put it in `.minecraft/mods/`, join a world or server, and type `/chattranslator` to open the settings. The Kotlin standard library is inside the jar, so Kotlin for Forge and Fabric Language Kotlin are not needed.

### Features

- **Chat**: Incoming lines are replaced with the translation on the same line, keeping ranks and name colors. Click `[Original]` at the end of a line to switch back
- **Item tooltips**: Lines of the same color are translated as one paragraph and wrapped to the original width. Hold `J` to see the original
- **Books**: Written books and books on lecterns are translated, starting with the open page
- **Sending chat** (off by default): Press Enter in the chat box to translate what you wrote (Japanese to English by default). You can check the translation before it is sent
- **Translation engines**: a built-in LLM (llama.cpp + TranslateGemma; free and offline; press Install in the settings), Claude, DeepL, Google, or any OpenAI-compatible API (Ollama, LM Studio and others)
- **Mod screens**: English, Japanese and Simplified Chinese

Settings are saved in `config/chattranslator-client.toml`. With a cloud API, the text being translated is sent to that service.
