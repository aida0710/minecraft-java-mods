内蔵 LLM に PLaMo 3 Translate を追加し、macOS でも動くようにしました。/ Adds PLaMo 3 Translate to the built-in LLM and makes the built-in LLM work on macOS.

紹介ページ / Website: https://aida0710.github.io/minecraft-java-mods/chat-translator/

## 日本語

### 使うローダーの jar を 1 つ選ぶ

対応: Minecraft 26.3 / Java 25

| ローダー | jar | 必要なもの |
| --- | --- | --- |
| Forge 66 以降 | `chattranslator-forge-0.3.0.jar` | |
| NeoForge 26.3.0 以降 | `chattranslator-neoforge-0.3.0.jar` | |
| Fabric Loader 0.19.5 以降 | `chattranslator-fabric-0.3.0.jar` | Fabric API |

### 追加したもの

- **PLaMo 3 Translate**: 内蔵 LLM で 0.8B / 2B / 8B を選べます。翻訳元の自動検出にも対応します。Built with PLaMo
- **macOS**: Apple silicon と Intel の Mac で内蔵 LLM が動きます。Apple silicon は GPU (Metal) を使い、Intel は CPU で動きます
- **形式の選択**: PLaMo と TranslateGemma のどちらでも、次の形式を選べます。OS で動かない形式は選択リストに出ません

| 形式 | 推論サーバー | 動く環境 | 追加のダウンロード |
| --- | --- | --- | --- |
| GGUF (おすすめ) | llama.cpp | すべての OS | 約 30MB〜 |
| MLX 4bit | mlx-lm | Apple silicon の macOS 14 以降 | 約 0.5GB |
| FP8・NVFP4 | vLLM | NVIDIA GPU の Linux と、Windows の WSL2 | 約 9.5GB |

Python を入れておく必要はありません。mlx-lm と vLLM を使うときは、mod が環境を作ります。

### 0.2.0 から更新するとき

- 内蔵 LLM の既定のモデルが、TranslateGemma 4B (約 2.5GB) から PLaMo 3 Translate 0.8B (約 0.6GB) に変わります。更新後にもう一度「インストール」を押してください。TranslateGemma を続けて使うときは、「翻訳エンジン」タブの「モデル」で選び直します
- 設定の `builtin.modelUrl` と `builtin.modelSha256` は使わなくなりました。モデルは `builtin.model` と `builtin.format` で選びます
- PLaMo はポルトガル語・スウェーデン語・デンマーク語・フィンランド語・ノルウェー語・チェコ語・ルーマニア語・トルコ語・ウクライナ語・ギリシャ語に対応していません。これらを使うときは TranslateGemma を選んでください

### 動作を確かめていないもの

- RTX 50 シリーズでの NVFP4 と、RTX 40 シリーズ以降での FP8 本来の動き (RTX 3080 Ti では、FP8 は重みだけ FP8 で動き、NVFP4 は起動に失敗しました)
- WSL2 の中で GPU を使って vLLM を動かすこと
- TranslateGemma の FP8・NVFP4 の翻訳
- Mac の実機 (macOS の確認は GitHub Actions の仮想環境で行いました)

## English

### Pick the jar for your loader

Requires Minecraft 26.3 and Java 25.

| Loader | Jar | Also needs |
| --- | --- | --- |
| Forge 66 or later | `chattranslator-forge-0.3.0.jar` | |
| NeoForge 26.3.0 or later | `chattranslator-neoforge-0.3.0.jar` | |
| Fabric Loader 0.19.5 or later | `chattranslator-fabric-0.3.0.jar` | Fabric API |

### What's new

- **PLaMo 3 Translate**: Choose 0.8B, 2B or 8B for the built-in LLM. It can also detect the source language. Built with PLaMo
- **macOS**: The built-in LLM runs on Apple silicon and Intel Macs. Apple silicon uses the GPU (Metal), and Intel runs on the CPU
- **Model formats**: Both PLaMo and TranslateGemma come in the formats below. Formats that do not run on your OS are not listed

| Format | Inference server | Runs on | Extra download |
| --- | --- | --- | --- |
| GGUF (recommended) | llama.cpp | Every OS | About 30 MB or more |
| MLX 4bit | mlx-lm | macOS 14 or later on Apple silicon | About 0.5 GB |
| FP8, NVFP4 | vLLM | NVIDIA GPUs on Linux, or WSL2 on Windows | About 9.5 GB |

You do not need to install Python. The mod sets up the environment for mlx-lm and vLLM.

### Updating from 0.2.0

- The default built-in model changes from TranslateGemma 4B (about 2.5 GB) to PLaMo 3 Translate 0.8B (about 0.6 GB). Press Install again after updating. To keep using TranslateGemma, choose it under Model on the Engine tab
- The settings `builtin.modelUrl` and `builtin.modelSha256` are no longer used. Use `builtin.model` and `builtin.format` instead
- PLaMo does not support Portuguese, Swedish, Danish, Finnish, Norwegian, Czech, Romanian, Turkish, Ukrainian or Greek. Choose TranslateGemma for these languages

### Not verified

- NVFP4 on RTX 50 series GPUs, and FP8 at full speed on RTX 40 series or later (on an RTX 3080 Ti, FP8 ran with FP8 weights only, and NVFP4 failed to start)
- Running vLLM on a GPU inside WSL2
- Translating with the FP8 and NVFP4 versions of TranslateGemma
- Real Macs (macOS was checked in GitHub Actions virtual machines)
